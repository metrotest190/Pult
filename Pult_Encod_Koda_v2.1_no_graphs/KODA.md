# Системные инструкции для ИИ (STM32F103 & STM32CubeIDE)

## 1. Аппаратный контекст
- **Микроконтроллер:** STM32F103 (Ядро ARM Cortex-M3, 32-бит).
- **Особенности архитектуры:** Отсутствует аппаратный блок вычислений с плавающей точкой (No Hardware FPU). Все вычисления с `float` и `double` выполняются программно (Software floating-point). Будь эффективен при работе с математикой в прерываниях.
- **Тактирование:** Максимальная частота системы (SYSCLK) — 72 МГц. При расчете таймеров (TIM) учитывай частоты шин APB1 (макс. 36 МГц, для таймеров удваивается до 72 МГц) и APB2 (макс. 72 МГц).

## 2. Среда разработки и библиотеки
- **IDE:** STM32CubeIDE (компилятор GNU GCC ARM Embedded).
- **Драйверы:** Строгое использование библиотек **STM32F1xx HAL** (Hardware Abstraction Layer) или **LL** (Low-Layer), если это явно указано в запросе. Не используй устаревшую библиотеку SPL (Standard Peripherals Library).

## 3. Критическое правило CubeMX (Защита кода)
- При изменении или добавлении кода в файлы, сгенерированные STM32CubeMX (например, `main.c`, `stm32f1xx_it.c`), ты обязан размещать свой код **СТРОГО** внутри комментариев-маркеров:
  `/* USER CODE BEGIN ... */`
  `/* USER CODE END ... */`
- **Запрещено:** Вносить изменения вне этих блоков. Если ты перезапишешь код вне маркеров, при следующей генерации проекта в CubeMX он будет безвозвратно удален.

## 4. Стандарты написания кода
- **Обработка ошибок:** Всегда проверяй возвращаемые значения функций HAL. Они возвращают тип `HAL_StatusTypeDef` (`HAL_OK`, `HAL_ERROR`, `HAL_BUSY`, `HAL_TIMEOUT`). Напиши обработку сбоя, а не игнорируй её.
- **Типы данных:** Используй строгие типы из `<stdint.h>` (`uint8_t`, `int16_t`, `uint32_t`) вместо стандартных `char`, `short`, `int`.
- **Работа с прерываниями (ISR):** Код внутри обработчиков прерываний должен быть максимально коротким и быстрым. Запрещено использовать `HAL_Delay()` или тяжелые функции внутри ISR. Используй флаги (volatile переменные) для выноса логики в главный цикл `while(1)`.
- **Атомарность:** При изменении глобальных переменных в прерываниях всегда добавляй ключевое слово `volatile`.
