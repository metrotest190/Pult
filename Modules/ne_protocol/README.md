# NeModbus — контракт обмена пульт ↔ ПК

Короткая спецификация того, что реально реализовано на стороне пульта:
формат пакета, обслуживаемые команды, правила ответов. Полный список
констант — в `ne_commands.h`; здесь только то подмножество, которое пульт
действительно обрабатывает (`Core/Src/main.c::NeOnPacket`, транспорт —
`ne_port.c`).

## Транспорт

| Параметр | Значение |
|---|---|
| Порт | USART1, 115200, 8N1 |
| Роли | ПК — мастер; пульт только принимает `SET_*` и отвечает на `GET_*` |
| Байт-порядок | big-endian во всех многобайтовых полях |
| Пакет | 14…142 байта (заголовок 10 + данные 0…128 + CRC 4) |

## Формат пакета (версия 1)

| Смещение | Размер | Поле |
|---|---|---|
| 0 | 2 | стартовое слово `0xA55A` |
| 2 | 2 | версия `0x0001` |
| 4 | 4 | код команды (u32) |
| 8 | 2 | `data_len` (u16), 0…128 |
| 10 | `data_len` | данные |
| 10 + `data_len` | 4 | CRC32 |

CRC32 считается по байтам `0 … 9 + data_len` (заголовок и данные, без самого
поля CRC) и является стандартным CRC-32 как в zlib/PNG: отражённый полином
`0x04C11DB7` (`0xEDB88320`), init `0xFFFFFFFF`, xorout `0xFFFFFFFF`.

Приём: поиск стартового слова, проверка версии, `data_len <= 128`, сверка CRC.
Пакеты с чужой версией, `data_len > 128` или неверным CRC отбрасываются молча.

## Обслуживаемые команды

| Команда | Код | Payload запроса | Действие на пульте |
|---|---|---|---|
| `NE_CMD_SET_TEST_SIGNAL_POSITION_VALUE` | `0x00000049` | float32, 4 б. | L → канал `x0` экрана |
| `NE_CMD_SET_TEST_SIGNAL_STRAIN_VALUE` | `0x0000004A` | float32, 4 б. | F → канал `x1` |
| `NE_CMD_SET_TEST_SIGNAL_DEFORMATION_VALUE` | `0x0000009F` | float32, 4 б. | D → канал `x2` |
| `NE_CMD_SET_HW_CMD` | `0x00000046` | int16, 2 б. | быстрая команда: `0` — отпущено, ≠ 0 — нажато |
| `NE_CMD_GET_TEST_SIGNAL_POSITION_VALUE` | `0x01000049` | — | ответ: текущий L (float32) |
| `NE_CMD_GET_TEST_SIGNAL_STRAIN_VALUE` | `0x0100004A` | — | ответ: текущий F (float32) |
| `NE_CMD_GET_TEST_SIGNAL_DEFORMATION_VALUE` | `0x0100009F` | — | ответ: текущий D (float32) |
| `NE_CMD_GET_HW_CMD` | `0x01000046` | — | ответ: текущая быстрая команда (int16) |

Правила:

- Ответ на `GET_*` — пакет с тем же кодом команды и payload того же типа;
  отдельного бита «ответ» в формате нет.
- `ACK`/`NACK` и сообщений об ошибках пульт не отправляет.
- Незнакомые и неподдерживаемые команды игнорируются молча.
- Неверная длина payload (`≠ 4` для float, `≠ 2` для int16) — команда
  игнорируется целиком.
- `NaN`/`Inf` во float заменяются на `0.0`.
- Если передатчик занят, ответ на `GET_*` теряется — запрос нужно повторить.

## Что не обслуживается

- Остальные коды из `ne_commands.h` (PID, режимы, калибровки, защиты и т. п.)
  на пульте не реализованы.
- Старые Modbus-регистры, включая диагностику `0x3000…0x3007` (статус TJC,
  зафиксированный пик L/F/D), не перенесены.
- Четвёртый канал экрана (`x3`) собственной команды не имеет и остаётся `0`.

Значения L/F/D передаются без масштабирования; пульт показывает их с тремя
знаками после запятой (L = 12.5 → на экране `12.500`).

## Пример

Установить L = 12.5 (`float32` = `0x41480000`), команда `0x49`:

```
A5 5A 00 01 00 00 00 49 00 04 41 48 00 00 90 66 7B 4D
└ start ┘ └ver ┘ └── cmd ──┘ └len ┘ └─ data ─┘ └── CRC ──┘
```
